# 突破压力位的量价关系：st-breakout-volume

> 研究性质：只读、事后研究；不构成交易建议，不接入任何实盘路径。登记时间：2026-10-12（America/Los_Angeles）。

## 事先登记（在读取结果前）

### 数据、样本与复权

- 数据为 `/Users/papa/codebase/n8n/state/research/shortterm_tactics_20261013/data/daily_panel.parquet`，按 `symbol`、`di` 排序；交易日边界使用面板的 `trading_date`。
- 主样本为 `~is_st_like` 的沪深 A 股日线，且相应前视字段存在；不使用北京股票、停牌日或缺失前视结果。开发段为 2023-08-15--2025-12-31，留出段为 2026-01-01--2026-09-18。留出段在所有定义、阈值和脚本固定后只读取一次。
- 原始价格不复权。对每只股票，定义日 `t` 的除权因子为 `factor_t = pre_close_t / close_{t-1}`（按相邻存储日；没有相邻前一条记录则不计算）。建立后复权价格：每个历史日的 `open/high/low/close/pre_close/limit_up` 乘以该日之后所有因子的乘积；因此滚动高点先在同一复权尺度计算，再与 T 日复权收盘比较。量、额不复权。登记并报告复权使突破分类改变的 stock-days 数量。
- `prior_high_N(T)` 是 T 之前按 `di` 连续存在的 N 个交易日的复权 `high` 最大值；不足 N 日不纳入。所有“前 N 日”特征只用 T 收盘前已知信息。

### 突破事件与共同统计口径

- N 取 20、60、120。T 为“首次突破”：复权 `close_T > prior_high_N(T)`，且 T-1 至 T-5 的每一日复权收盘均不高于各自当日的 `prior_high_N`（至少五个交易日没有收盘突破）。若这些历史行缺失则不判定。
- 事件特征：`vr` 使用面板定义（当日 amount / 过去 20 根 amount 均值）；固定量比箱为 `<1`、`1-2`、`2-4`、`>=4`，并另按当日所有合资格样本的 `vr` 做三等分（低/中/高）。日内振幅为 `(adj_high-adj_low)/adj_pre_close`，上影为 `(adj_high-max(adj_open,adj_close))/adj_pre_close`；两者的低/中/高阈值均只用开发段全部突破事件的 1/3、2/3 分位数固定到留出段。涨停收盘使用当日 `limit_up_close`。
- 结果变量：next open 为 `overnight1`（T 收盘到 T+1 开盘），next close 为 `ret1`（T 收盘到 T+1 收盘），3-day 为 `ret_2_3`，可实现买入结果为 `o2o`（T+1 开盘买入、T+2 开盘卖出；若 `next_open_at_limit_up` 则不可买，排除该 stock-day）。持有到 T+1 收盘的结果仍报告，但不能假定 T+1 日内卖出；T+1 跌停不能卖出的观察按面板的 `next_limit_down_close` 标记并报告。
- 每个比较先在同一交易日对股票取均值，再对交易日均值做均值和 `t = mean(day_value) / (sd(day_value)/sqrt(days))`；同时报告交易日数和 stock-days。两组差异统一写为“后者减前者”。缺失结果不插补。
- 通过规则：开发段须达到预先方向且 `|t| >= 3.9`，留出段同方向且 `|t| >= 2.0`；两段均满足才写“成立”，否则“未支持”。所有登记的 outcome 和分组都保留在结果表中。

### H1：突破量价、涨停与形态

在每个 N 下，比较首次突破事件的：

1. 固定量比四箱及当日量比三等分；重放量方向预期为量比越高，T+1 next open、next close、3-day、o2o 越高。
2. `limit_up_close` 与非涨停收盘；预期涨停收盘不劣于非涨停（四个结果同方向）。
3. 振幅低/中/高、上影低/中/高；预期更大的振幅和更长上影不提高后续结果（高组减低组应非正）。

### H2：平台突破

- 平台宽度为 `(max(adj_high)-min(adj_low))/min(adj_low)`，只在 T 前 N 个交易日计算。对每个 N，以开发段所有可判定 T 的平台宽度第 20 百分位为固定窄平台阈值；宽度不高于阈值定义“窄平台”。
- 在窄平台首次突破中重复 H1 的量比四箱/三等分比较，并与同 N 的全部首次突破比较。平台突破的登记方向为：窄平台突破相较非窄平台突破的 next open、next close、3-day、o2o 更高；需满足同一双段 t 规则。

### H3：触及压力位但收回（放量滞涨）

- T 的复权 `high_T >= 0.99 * prior_high_N(T)` 且 `close_T < prior_high_N(T)`，视为触及/越过压力后收回；T-1 至 T-5 不要求突破事件条件。按固定量比四箱和当日量比三等分比较，另报告上影高/低三等分。
- 登记方向：重放量收回（`vr>=2` 或高量比三等分）相较轻量收回（`vr<1` 或低量比三等分）的 next open、next close、3-day、o2o 更差（后者减前者为负）。

### H4：首板与 60 日压力位

- T 满足 `streak==1` 且 `limit_up_close`。以 `prior_high_60(T)` 比较：A 组 `adj_close_T > prior_high_60`；B 组 `adj_close_T < prior_high_60`；C 组为涨停价低于但不超过压力位 1%：`0 <= prior_high_60-adj_limit_up_T <= 0.01*prior_high_60`。组间允许不互斥但 C 必须 `adj_limit_up_T < prior_high_60`。
- 结果除四个共同 outcome 外，增加 T+1 是否涨停收盘（按 `di+1` 对齐的 `next_limit_up_close`）。决策时点为 T 收盘；若研究 T+1 开盘可买性，`next_open_at_limit_up` 的观察单独标记，不把不可买样本当作可实现 o2o。
- 为接上 README 的基线，首板 A/B/C 的再次涨停率同时按 T+1 开盘 gap 分箱（`<-2%`、`-2%--0%`、`0%-2%`、`2%-5%`、`5%-9%`、`>=9%且未开在涨停`）报告，并给出全体昨日涨停股按 `streak` 的同一分箱基线；不把 gap 事后当作 T 收盘时已知的信号。
- 登记方向：A 的再次涨停率和四个收益高于 B；C 的再次涨停率和收益低于 A。只有在 gap 分箱内仍同方向且满足双段 t 规则，才称为增加了 board-count/open-gap 基线。

### H5：突破前缩量整理后放量

- 对首次突破 T，前五个连续交易日的成交量为 `v_{T-5},...,v_{T-1}`。定义 `shrink5 = mean(v_{T-5:T-3}) >= 1.20 * mean(v_{T-2:T-1})`；缺任何一日则不判定。按 `vr_T>=2`（放量突破）与否则分别报告 `shrink5` 与非 `shrink5`。
- 登记方向：在相同 `vr_T` 层内，`shrink5` 相较非 `shrink5` 的 next open、next close、3-day、o2o 更高；需同时满足开发与留出方向/t 门槛。

## 一句话结论与结论表

在这份样本和预先登记的门槛下，“突破时放量更值得跟随”没有通过：突破量比越高，N=20、60 的次日开盘/收盘差异反而为负；“放量滞涨”在次日持有收益上较差，但可实现 `o2o` 的留出段没有达到门槛；没有规则同时通过开发段和留出段。

## 各条规则的结果补充

### H1 突破量价、涨停与形态

固定量比箱的方向最清楚：开发段 N=20 的 `vr<1`、`1-2`、`2-4`、`>=4` 的次日收盘均值分别为 +1.766%、+0.452%、+0.220%、+0.038%；留出段为 +1.742%、+0.313%、+0.041%、-0.151%（对应 ARM 行）。这不是“越放量越强”的单调关系。量比三等分同样呈低量更高、重量更低；但在 N=120 的留出固定箱中，重箱的次收差异没有达到门槛，因此不能泛化为稳定规则。

涨停收盘组的次日收盘在开发/留出为 +2.031%/+1.683%，非涨停组为 -0.184%/-0.194%；但涨停组的 `o2o` 为 -0.669%/-0.254%，且留出 `o2o` 差异 t=-2.50，说明“封住”与可买入后的隔夜实现不是同一件事。振幅和上影的高低比较在四个 outcome 上不一致，均未通过。

### H2 平台突破

窄平台阈值只用开发段定义。N=20 开发窄平台的次收为 +0.120%，非窄为 +0.342%；留出为 +0.062% 与 +0.296%。N=60、120 的对应比较也没有四个 outcome 同向，故“窄平台突破更好”未支持。

### H3 放量滞涨

触及/越过前高 1% 内但收盘跌回的事件规模为开发 N=20 286,883 stock-days/558 日、N=60 112,656/518、N=120 64,369/458；留出为 89,348/171、34,511/170、22,232/168。重量组的隔夜和次收普遍更差，开发 N=20 重量相对轻量分别 -1.529%/-33.01 与 -0.961%/-11.66，留出分别 -1.174%/-12.15 与 -0.648%/-3.34；但可实现 `o2o` 留出 t=-1.48（N=20），没有达到 2，故按预登记规则不能称为成立。上影高低组方向相反或不稳定。

### H4 首板与 60 日压力位、基线

开发 A（收盘在 60 日高上方）再次封板率 21.014%，B（收盘在下方）17.419%；留出为 15.615% 与 13.781%。差异的收益 t 值和 o2o 没有在两段达到完整门槛。C（涨停价低于压力位但差不超过 1%）封板率为开发 21.258%、留出 16.726%，样本仅 795/281 stock-days，不能据此宣称优于 A。

作为 README 基线的同口径首板 gap 分层，留出全体首板的 T+1 再封板率依次为 `<-2%` 2.710%、`-2%-0` 2.907%、`0-2%` 7.393%、`2-5%` 18.991%、`5-9%` 37.442%、`>=9%` 65.358%；A 组对应为 2.233%、3.860%、6.923%、17.638%、31.287%、62.069%，B 组为 2.996%、2.502%、7.559%、19.562%、41.393%、68.111%（输出 `GAP_BASELINE` 行）。A/B 的差异在 gap 分层后并没有稳定地保留“线上方更好”，所以没有增加 README 的 board-count/open-gap 基线。

### H5 突破前缩量整理后放量

`shrink5` 的开发定义是前三日平均量至少为最近两日平均量的 1.2 倍，并只在 T `vr>=2` 的突破内比较。N=20 开发 shrink 相对 no-shrink 的次收 +0.263%/t=+2.51，但 3 日 -0.048%/t=-0.34；留出次收 +0.378%/t=+1.78、o2o +0.456%/t=+1.92，均未达到留出门槛。N=60、120 的留出差异也未通过，因此不能把该形态列为候选规则。

## 可进入“组合战法”的候选规则

无。没有登记规则同时满足开发段 `|t|>=3.9`、留出段同方向 `|t|>=2`、四个结果整体同向和可交易口径；因此不把任何结果转成阈值、推荐或实盘逻辑。

## 局限与没做到的

- 面板明确有 2026-08-28、2026-09-11 的前视字段缺失，以及 2026-09-21 以后部分股票行缺失；留出段截至 2026-09-18，因此主要影响是可用样本减少，未插补。
- `vr` 依赖 amount20；研究按协议直接使用面板字段，没有把异常 amount 重新校正。量比箱和日内排序可降低量纲影响，但不能消除供应商金额异常。
- “同日三等分”是描述性日内相对量，不是跨日固定阈值；它只使用 T 当日的横截面特征，不使用结果。平台、振幅和上影阈值只在开发段估计并冻结。
- 输出按交易日聚类，未拟合更复杂的股票固定效应、行业效应或多重检验校正；因此预登记的 3.9/2 门槛是本研究的保守判定，不是总体因果证明。
- 首板 gap 分层是用于对接 README 基线的事后结果分层，不作为 T 收盘时可知的入场信号；`next_open_at_limit_up` 与跌停不可交易标记被保留，未把不可实现收益当作可实现交易结果。
- `limit_up_lists.parquet`、晨会竞价文件和 `cycle_series.json` 未用于主结论；本研究没有对量价规则加入盘口、题材或资金流控制，也没有声称样本外更长时期成立。
