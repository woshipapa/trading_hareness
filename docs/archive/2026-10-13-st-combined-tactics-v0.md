# 龙头短线组合战法 v0（2026-10-13）

研究记录，不是交易建议，不接入任何下单路径。数字都是“2025 年底以前 / 2026 年 1–9 月”两段，括号里是按交易日
聚类的 t 值。样本：2023-09 至 2026-09 的沪深涨停股（约 4.7 万个股票日），除非另注。

来源：老师的八场复盘和五节课（`teacher_method_digest.md`，规则编号 R01–R55）；五路调研
（`docs/archive/2026-10-13-st-*.md`）；我对关键数字的独立复算（`checks/` 里的脚本和输出）。

## 一、结论

1. **老师的选股框架被数据支持。** 强题材里最早封板的龙头、封单足、不放量、不是尾盘板——这些他反复讲的条件，
   次日表现都明显更好，两段都成立。
2. **数据支持的是“拿什么、躲什么”，不是“开盘就买”。** 所有规则在“次日开盘买入”口径下都不显著为正。这和老师
   自己的做法一致：他的买点在开盘后几分钟（卡位、开板回封、放量进攻），不在竞价挂单。
3. **所以战法分两半：** 前一晚和 09:25 用已验证的规则定“持有 / 回避 / 观察名单”；盘中买点先登记成试验规则，
   用 10 月 13 日起采的竞价和分钟数据每天试。
4. 老师有两条说法和数据相反或不稳，见第三节。

## 三之三、卖点：前面的收益口径不完整（2026-10-13 更正）

前面所有表都只用“次日收盘”或“次日开盘买、再下一个开盘卖”来算收益。卖法本身就能把结果挪动 0.5–1 个点，
和大多数选股条件的作用一样大。脚本 `checks/exit_rules_check.py`、`exit_rules_buyer_check.py`，只用日线。

**持有昨日涨停股的人（从涨停日收盘算起，次日卖）**

| 卖法 | 全部涨停股 | 连板股（2 板以上） |
|---|---|---|
| 次日最高价（上限，事先不可知） | +6.68% / +5.76% | +7.90% / +7.23% |
| 次日开盘卖 | +2.34% / +1.69% | +3.54% / +2.95% |
| 次日收盘卖（前面各表的口径） | +1.95% / +1.57% | +2.68% / +2.71% |
| 冲高 5% 挂单止盈，没到就收盘卖 | +2.84% / +2.01% | +4.25% / +3.75% |
| 跌 3% 止损，否则收盘卖 | +1.56% / +1.21% | +2.22% / +1.98% |
| 封住就拿到后天开盘，没封收盘卖 | +2.95% / +2.16% | +4.56% / +4.06% |
| 按跳空处置（一字拿；高开 ≥5% 未封开盘卖；其余收盘卖）并且封住续拿 | +3.01% / +2.16% | +4.68% / +4.09% |

- 最高价平均比收盘价高 4.7 / 4.2 个点：这是卖点规则能争取的空间，挂单止盈只拿到其中 0.5–1.5 个点。
- 机械的 3% 止损在每一组里都比不止损差，因为这类票日内下探后常收回。
- 同一天既摸到 +5% 又摸到 −3% 的占 10.5%，日线分不出先后，所以“止盈 + 止损”的结果是一个区间
  （全部涨停股：先止损 +1.96% / +1.39%，先止盈 +2.91% / +2.09%），要分钟线才能定。

**次日开盘买入昨日涨停股的人（一字买不进的不算）**

|---|---|---|---|
| 再下一个开盘卖（前面各表的口径） | −0.91% / −0.45% | −0.78% / −0.39% | −0.50% / −0.20% |
| 再下一个收盘卖 | −0.48% / −0.05% | −0.36% / −0.05% | +0.17% / +0.35% |

| 次日封住续拿，否则收盘卖 | −0.20% / +0.12% | −0.11% / +0.12% | +0.39% / +0.39% |
| 亏 3% 止损，否则收盘卖 | −1.00% / −0.38% | −0.91% / −0.32% | −0.35% / +0.05% |

- 之前说“开盘买入不为正”，用的是最差的那种卖法。换成较好的卖法，不加选股条件时大约打平（未扣交易成本）；
  加上选股条件后能否为正，要在试验台里按“条件 + 买入方式 + 卖出规则”一起算。
- 前面各表里“条件 A 比其余涨停股强/弱”的方向没有变：例如缩量平量板对放量板，按收盘卖差 +2.03 / +0.89
  个点，按最好的卖法差 +3.00 / +1.42 个点，差距更大。但绝对收益数字都应按上表重读。

**下一步**：卖出规则和条件一样登记进试验台（第一批 13 条：开盘、收盘、3/5/8% 止盈、3% 止损、止盈止损两种

## 四、组合战法 v0（按时间线）

### 前一晚：定名单

**持有 / 观察的对象（同时满足越多越好）**
- 所在题材当天涨停 ≥7–10 只（成立）。
- 是该题材里最早封板的那只（成立，仅对持有者）。
- 全市场最高板：次日收盘 +3.2% / +3.9%，再封板 56% / 46%（成立，仅对持有者）。

**回避 / 减仓信号（任一条都使次日大面率抬高 4–11 个点）**
- 收盘封单 < 2000 万。
- 当天量比 ≥3，或成交额创 250 日最大。
- 首封在 14:30 之后。
- 所在题材涨停 ≤3 只。
- 此前 20 日已涨 ≥40%。
- 大面风险分排在前五分之一（已上线：19.0% 对 8.5%）。

### 09:15–09:25：只做处置，不做买入

- 连板股一字开盘：继续持有（封住 81.8% / 81.5%）。
- 低开 2% 以上：不在开盘砍，开盘到收盘平均 +1% 到 +2%。
- 高开 5% 以上但没一字：冲高回落的多，开盘到收盘 −0.8% 到 −2.6%。
- 竞价金额排在昨日涨停股前五：再封板率高 12.1 / 6.1 个点（试验）。
- 连板股高开低于该板数的常见幅度：开盘买入 −3.1% / −2.3%（试验，样本少）。

### 开盘后 5–15 分钟：老师的买点，全部是试验规则

卡位（R03）、开板后的量和回封（R18）、放量进攻且强于大盘（R24）、同梯队赛马（R12）。历史数据验不了，
用新采的竞价逐秒快照和分钟快照登记后每天试。

### 总开关

没有成立的规则。老师的两个开关（连板环境、两市成交额）按字面定义都不支持，登记为试验，成交额改成
相对近 60 日的位置再试。“最高板断板后整体回避”只在前段出现（开盘买入 −1.57%，后段 −0.27%），登记为试验。
