# Quant Console Backend Audit (Phase 1)

## Scope and evidence

Phase 1 is a static inventory from base `bb2d918d7715487f8f060ade7773fb0032cd487c`; it ran no HTTP request, browser session, or write action. Phase 2 then ran the documented GET-only per-endpoint probes and one read-only browser pass through edge adapter `http://127.0.0.1:18300` and owner read path `http://127.0.0.1:15682`. Phase 3 below uses only those recorded measurements and source traces; it makes no new request.

The inventory covers the mounted research shell, every research tab, the personal-decision view, their composables/components, and the adapter `/health` read. It contains 109 distinct `/api/research/...` paths plus `/health` (110 rows). The per-view row counts are Provider tab 4, Strategy tab 4, Personal decision 2, Remote realtime 12, Analyst evidence 5, Close review 10, Factor lab 3, Market snapshots 9, Research overview 6, Research shell loader 47, Stock study 2, Sentiment temperature 2, Session radar 4.

GET transport is `cache: no-store` and queued at 12 reads (`frontend/src/api/http.ts:11-18`, `frontend/src/shared/http.ts:75-85`). Adapter read forwarding is at `feishu-relay/adapter/index.mjs:1995-2004`; action forwarding is at `feishu-relay/adapter/index.mjs:2007-2027`. Template routes and parameter rules are at `feishu-relay/adapter/research-routes.mjs:141-195`.

## Findings

### Measurement path and scope of conclusions

Every browser and adapter number in this audit used the Mac's SSH forward to edge `127.0.0.1:18300`; it bypassed Caddy and multiplexed requests over one SSH channel. Owner-direct samples used a separate SSH forward to `127.0.0.1:15682`. Therefore the following findings do not depend on the public transport: the shell fires 47 research reads even though the first visible tab needs four of them; the runtime refresh is an 11-request fan-out every 15s; the heavy owner projections really take seconds and return megabytes; `feishu-relay/adapter/index.mjs:1995-2004` buffers the complete body, sends `cache-control: no-store`, and has no research cache or explicit concurrency limit; and its fetch-error handler returns 503 (`feishu-relay/adapter/index.mjs:2038-2045`).

The absolute browser values are path-specific: 87.140s until the last first-load request settled, 29,246.9ms maximum browser queueing, and 2,203,935B of uncompressed first-load JS/CSS can differ on the public URL. `deploy/Caddyfile:12-17` places `encode zstd gzip` and `reverse_proxy feishu-adapter:3000` in front of the relay domain; HTTPS Caddy may negotiate a modern protocol, but this checkout does not establish what a user's browser actually negotiates. The exact settling measurement is a normal browser run at the public relay URL recording, for every response, `response.protocol`, `content-encoding`, `cache-control`, transferred bytes, and CDP request timing/queueing, then comparing the same cold `/research` load and tab sequence. No such public-path measurement was run.
