# 竞价玩法：09:25 开盘竞价列表研究

## 一句话结论

09:25 列表主要是按竞价金额排序的榜单；在 gap 与 boards 基线内，爆量高开和高开不及预期均未通过双段门槛，top10 的 o2o 只在开发段同向而留出段未达 t 门槛，不能形成已验证的可交易规则。

## 事先登记（2026-10-12，Pacific Time）

### 数据、切分与统计

- 数据源为共享 README 指定的 `morning_auction_lists.jsonl.gz`、`daily_panel.parquet`、`limit_up_lists.parquet`；交易日按列表日期匹配，决策时点为 T+1 的 09:25。
- 开发段为 2023-09-01 至 2025-12-31；留出段为 2026-01-01 至 2026-09-18。留出段在所有定义、阈值和脚本固定后只读取一次。
- 股票结果按交易日先求均值，再用日均值的标准误计算 day-clustered t；同时报告交易日数和 stock-days。开发段需同方向且 |t|≥3.9，留出段需同方向且 |t|≥2，才判为“成立”。其余为“不支持”。
- 仅使用决策时已知字段；开盘涨停不可买入，跌停不可卖出；买入开盘后的当日不可卖出，使用 `o2o` 表示下一开盘到再下一开盘，持有者另报下一收盘。

### 先验解码假设（字段位置从 0 开始）

对每个位置，先与 panel 的 `gap`、`ret`、`amount`、`float_cap` 及可从其导出的换手率/自由流通市值、以及 limit-up list 的主力买卖字段逐一比对；只有跨样本高一致率的映射进入分析。无法验证的位置不使用。列表的排序和入选机制由字段映射、日内排名及覆盖率描述，不预设具体结论。

### 规则定义与方向

所有规则均在 T+1 09:25 决定，并以昨日 T 收盘涨停股为主样本，结果在当天 gap bucket 和 T 的 boards 分层内报告：

1. **竞价爆量高开**：竞价金额 / T 的日成交额 ≥ 预注册阈值（开发段中位数以上的固定分位阈值，阈值由开发样本的 75% 分位确定后冻结），且 T+1 gap ∈ [2%, 7%]；方向为相对同一 gap、boards 单元的封板率更高、open-to-close 不更差且 `o2o` 为正。
2. **竞价抢筹**：列表可验证的主力净买入 / 竞价金额 > 0 且位于开发段日内横截面最高 25%；方向为相对同单元封板率更高、open-to-close 和 `o2o` 更高。
3. **强板后高开不及预期**：T 的 boards ≥2 且 T+1 gap < 开发段按 boards 估计的中位 gap；方向为封板率更低、open-to-close 更差。
4. **一字开盘且薄对厚**：T+1 `open_at_limit_up` 为真，且可验证的卖方/买方竞价量字段中卖方明显薄于买方（比值阈值在解码后若能验证则冻结）；方向为次日封板/持有收益更高。若买卖量无法验证，则该规则报告未测试。
5. **竞价列表顶部选择**：按列表原始顺序的 rank≤10（以及按日内 rank 分位的 top 10% 作为敏感性）为选择；方向为相对同日其余列表股票以及同 gap、boards 单元的封板率、open-to-close、`o2o` 更高。
6. **非昨日涨停股的列表高位**：在列表但 T 未收涨停的股票中，rank≤10 与其余列表股票比较 T+1 开盘买入的 `o2o` 和下一收盘收益；方向为正。

对每条规则均报告样本数、估计值、day-clustered t、交易日数、stock-days和是否满足双段门槛；不支持的规则也保留在结果表。

## 结果

开发段脚本/输出为 [`02_development.py`](2026-10-13-st-auction-play-data/02_development.py) / [`02_development.txt`](2026-10-13-st-auction-play-data/02_development.txt)；留出段脚本/输出为 [`03_holdout.py`](2026-10-13-st-auction-play-data/03_holdout.py) / [`03_holdout.txt`](2026-10-13-st-auction-play-data/03_holdout.txt)。阈值固定后，最终留出结果来自修正后的一次完整运行（输出含 `holdout_read_once=true`）；首次格式错误重跑的协议偏离见“局限”。所有结果均按日聚类并报告日数与 stock-days。

## 可以进入“组合战法”的候选规则

无。已测试规则没有同时满足开发段 |t|≥3.9、留出段同方向 |t|≥2 的可交易条件；两个需要未解码字段的规则不能进入候选。

## 局限与没做到的

- 位置 6–11、16 未能从 panel 或 limit-up list 独立验证；因此没有声称它们是买卖量、未成交量或其他盘口变量。
- p13–p15 是收盘后 limit-list 字段的复制，不是 09:25 竞价主力净买入/买入/卖出；“竞价抢筹”未测试。
- “一字开盘薄对厚”缺少可验证买卖盘量，且一字涨停开盘不可买，未测试。
- panel 已知的 forward 缺失日和部分缺行日按原数据保留；不可交易的开盘涨停没有被当成可买入收益。研究只覆盖列表文件的 2023-09-01 至 2026-09-18 窗口。
- 金额比率使用 panel README 指定的异常成交额修正；极端比率仍以中位数和同日 gap/boards 细胞控制呈现，未把它们直接解释为因果。
- 留出脚本首次运行时只输出格式有误的计数行，随后在定义不变时重跑；因此从物理文件读取次数看是两次，最终报告数字来自修正后的第二次运行。这是对“留出只读一次”协议的偏离，已如实记录。
