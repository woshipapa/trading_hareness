# 龙头战法的数据分析（2026-10-14，未审计，只读）

数据：试验台的收盘读数 750 个交易日（2023-09-01 至 2026-10-13，重放生成，样本内），用结算函数和库里真实日线逐只结算；龙头类 12 个战法。提取脚本 `leader_extract.py`，分析脚本 `leader_analysis.py`，完整输出 `analysis.out.txt`。**什么都没有写库。**

## 结论

1. **龙头的溢价几乎全部在隔夜，次日开盘之后是亏的。** 选股次日：隔夜（S1 开盘 / 今收 − 1）选股均值 vs 当日其余均值：龙头持有 +6.83% vs +2.35%，二三板接力 +6.02% vs +2.32%，梯队竞速胜者 +7.08% vs +2.43%；盘中（S1 收盘 / S1 开盘 − 1）：龙头持有 −1.06% vs −0.36%，竞速胜者 −1.33% vs −0.35%。
2. **一半左右的龙头次日开盘就在涨停价。** 龙头持有 27.0% 一字 + 20.9% 开盘涨停后开板；梯队竞速胜者 32.9% + 22.0%；全部选股行是 5.4% + 5.6%。所以“持有到次日”的账只有一半能被买入者拿到。
3. **次日开盘买入到收盘，三种记账都是负的**（每笔均值）：账本（只记能买的）/ A（开板后按涨停价成交，一字记 0 不删）/ B（只要开盘涨停就记 0）：龙头持有 −0.89% / −1.06% / −0.46%（账本只有 648 笔，占 52%）；竞速胜者 −1.40% / −1.33% / −0.63%。A 比账本更负：龙头持有里，开板后按涨停价成交的那 260 笔当天平均 −2.87%（账本里的 648 笔正常开盘平均 −0.89%），一字的 336 笔记 0；梯队竞速胜者的开板那部分是 −3.16%，二三板接力 −2.81%。A 还假设开板后一定成交，是上限。
4. **有两个龙头条件看不出优势**：`全市场最高板` 日均差 +0.22%（t 0.57）、`龙头切换` +0.11%（t 0.36）。`梯队环境接力`按日算 t=3.20，按题材日分簇后 t=1.10，不稳。
5. **题材日不是主要的有效样本问题**：龙头类每题材日只有 1.0–1.1 只；`卡位持有` 3.8 只/题材日、`二三板接力` 2.2、`题材内前排` 2.4，按日分簇后 t 基本不变（8.4→8.6，12.4→12.2）。真正限制的是前向样本：今天只有 2 只“龙头持有”。

## 复权因子补齐并重放之后（2026-10-14 16:45）

2023–2024 年的读数用补齐的因子重放后（B078、B082），把提取和分析重跑一遍（`analysis_after_factors.out.txt`）：龙头持有的隔夜 +6.84% 对 +2.35%、盘中 −1.06% 对 −0.37%、次日一字 27.0% + 开板 20.9%、三种记账 −0.89% / −1.06% / −0.46%，与重放前的差别都在 0.02 个点以内，结论不变。

## 限制

- 样本内：条件是看过这批数据之后登记的。
- `held` 的口径是“前一日收盘持有”：对已封死的龙头，现实里要么前面已经持有，要么在收盘集合竞价排队，买不到的占多数；它不是可执行收益。
- （已解决）2023 年约一半日线原来没有复权因子（B002），分析最初用的是未复权价；B078 补齐、B082 重放之后重跑，结论不变，见上节。
- 日线没有涨跌停价时，结算用板块比例回退，且回退里 `is_st=False`（`t1_settlement._limits`）：2026-07-06 之前的主板 ST 股被当成 10% 板，封板和一字会被误判（B079）。
- 分析里的“开板”按日线最低价低于涨停价判断，不知道开板的时间和成交量。

## 怎么用

- 研究层面：龙头类战法的实际可执行版本只剩“盘前持有”和“集合竞价排队”，次日开盘买入这条路在样本里是负期望。
- 需要分钟线才能回答的两个问题：龙头在前一天什么时候封死、开盘后开板到回封的时间窗。（B077 每晚落涨停股分钟线。）
