# 0006 研究与老师策略默认不产生实盘效果

- 状态：生效
- 日期：2026-10-08

## 背景

系统里有很多研究策略、老师复盘策略和自动化闭环，其中任何一个都不应该因为
"已登记"或"测试通过"就影响真实决策或下单。

## 决定

- 研究和老师策略一律 fail-closed：`live_effect=none`，在
  `quant.strategy_promotion_registry` 里登记为 `disabled`、`max_live_weight=0`。
- 登记不授予执行权限；只有明确批准的研究版本才可以带非零权重。
- 本系统不下单、不写自选；owner/peer 数据检查都只读。
- 数据不完整（覆盖率不足、时间戳过期、非 2xx）时，结论是"证据失败"，不能转成交易
  判断。

## 后果

新策略上线要额外走一步审批；默认安全。

## 怎样保证

迁移 `20261008_sep0001` 写入三条 disabled、权重 0 的登记行；relay 契约
（`docs/COMPONENT_CONTRACTS.md`）要求把不完整的证据当作失败处理。
